# S7 3.1 Earned Value Management

## Learning Objectives

Describe the components that make up earned value management.

## Using the Earned Value Management Method

According to PMBOK 7, the Measurement performance domain evaluates the degree to which the work done in the Delivery performance domain meets the metrics identified in the Planning performance domain. For example, the baselines identified in the Planning performance domain are used to measure and evaluate performance. Timely and accurate information about project work and performance allows the project team to learn and determine the appropriate action to take to address current or expected variances from the desired performance.

There are several reasons why measures are used, including the following:

evaluating performance compared to the plan

tracking the usage of resources, work completed, budget expended, etc.

demonstrate accountability

providing information to stakeholders

assessing whether project deliverables are on track to deliver planned benefits

focusing conversations about trade-offs, threats, opportunities, and options

ensuring the project deliverables will meet customer acceptance criteria

We often mistake the value of measurements for the collection and dissemination of the data. However, the value is actually in the conversations about how to use the data to take appropriate action.

Therefore, while much of the Measurement performance domain addresses various types of measurements that can be captured, use of the measures occurs within the context of activities in other performance domains, such as project team and stakeholder discussions, coordinating project work, and so forth. Let’s begin to delve into a very popular method of measurement— earned value management (EVM).

Earned value management (EVM) is a widely accepted method of measuring project performance and progress of actual cost against the budgeted/planned cost. The earned value (EV) of a project is the total dollar budget of the work that has been completed. Once the value of the work completed is determined, it can be compared with the actual expenditures and the budgeted expenditures in order to assess the project’s progress toward completion.

EV measures both schedule and cost performance. The results of the analysis are used to understand the current state of the project and also to make predictions of what the budget performance will be at project completion.

The assessment of earned value can be done any time during a project’s execution phase and normally occurs at several key times. The EVA results allow the project manager to communicate performance results to the stakeholders and make decisions or recommendations for changes if the results do not align properly with the baseline budget and schedule.

EVA measures schedule and cost performance separately for a specific point in time. Project data are gathered for a specified time period such as “the end of the third week.” The value of work completed, actual cost, and value of work scheduled (budgeted) will all be reported based on that date. At that point, the project will be deemed either ahead or behind schedule and either over or under budget.

## Components of Earned Value Management

Preparing the earned value analysis requires four data elements from the project:

The earned value (EV) is the dollar value of all work completed to date. This is based on the baseline budgeted cost of each activity.

The planned value (PV) is the dollar value of all work scheduled to have been completed to date. This is based on the baseline schedule and the calendarized baseline budget.

The actual cost (AC) is the total dollar value of costs incurred to date. This includes work and invoices already paid as well as any expenses that have been incurred but not yet invoiced or paid.

The budget at completion (BAC) is the approved total baseline budget approved for the completed project.

To calculate EVA measures, the project manager must take into consideration the status of each activity or task in the project. The earned value of each activity is calculated by multiplying the budgeted cost with the percent complete. The earned value for activities that have not yet started is simply zero. The earned value for activities that are completed is 100% of their budgeted costs.

The difficulty arises when activities are partially complete. For activities that are partially complete or in progress, an appropriate percentage must be determined. Making the determination of the percentage to use can require significant study and judgment call because the percentage chosen will have a significant effect on the EVA results.

Consider an activity where 10,000 sq. ft. of carpet is to be installed. If at the time of the EVM analysis, 2,500 sq. ft. have been installed, then the project manager could simply use the ratio 2,500/10,000 = 0.25 or 25% complete. But what if the activity is to create 30 web pages and the developer has developed 15 of the pages? The project manager could assume that the activity is 50% complete (15/30 = 0.50), however, the pages may not all require the same level of effort. The developer may actually need significantly more time to complete the last 15 pages than was required to complete the first 15 pages. In that case, assuming that the developer is 50% complete would be inappropriate.

There are two methods that project managers often use to simplify the determination of the percentage complete when actual units completed do not adequately reflect the effort needed for completion.

The 50-50 rule assigns 50% complete as soon as an activity is started, and the activity is considered 100% upon completion. There are no percentages assigned in between, so every activity can quickly be assigned a value of 0%, 50%, or 100%.

A circle divided in half, with 50% at the top and 50% at the bottom.

The 0-100 rule assigns 0% to activities that have not been started and those that are in progress. Completed activities are assigned 100%. Every activity in the project is assigned a value of either 0% or 100%.

These two methods may seem a bit extreme; however, if applied consistently, they can be effective in assessing earned value. They are popular in practice because the alternative is to have everyone on the project stop working to meticulously calculate the percentage complete on their activities. The lost work and questionable accuracy of such estimates encourages the use of broad sweeping approaches such as the 50-50 and 0-100 rules.

Using the baseline budget developed for the five-week website project earlier in the course, the project manager can calculate the EV of the project at the end of Week 3. The following table shows the five major work activities along with their respective baseline budget. The percentage complete is assigned based on the 50-50 rule.

Activity 1.1 “Design” has been completed, so it is assigned a percentage complete of 100%. Activities 1.3 “Testing” and 1.5 “User Training” have not yet begun, so they are assigned a percentage complete of 0%. Activities 1.2 “Programming” and 1.4 “Documentation” have been started but have not yet been completed, so they are assigned completion percentages of 50%. Multiplying the activity level budget by their respective percentage complete provides the EV by activity. The activity level EV are summed to determine the overall EV of the project. In this case, the project’s EV is $42,500 at the end of Week 3.

Calculating the planned value (PV) for each activity follows a similar approach where the percentage complete is multiplied by the baseline budget for the activity. This is driven by the calendarized budget.

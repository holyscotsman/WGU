# S4 1 Summary

## Summary

This lesson compared and contrasted common project management methods and discussed how complexity and uncertainty affect the selection of a project management method. Building on the knowledge of how the project life cycle describes the doing of project work to the managing of the project itself, you learned PMBOK’s process groups are used for managing a project: initiating, planning, executing, monitoring and controlling, and closing. You saw examples of what happens during each of these steps. There are three major project management methods: traditional, agile, and extreme. This lesson defined each of these and identified the context for selecting each method, as well as outlining potential problems with using each method.

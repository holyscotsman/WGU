# S7 3 Introduction

## Learning Objectives

Consider the following learning objectives as you move through the lesson: Describe the components that make up earned value management. Determine the progress of a project given various earned value scenarios.

## Overview

In this lesson, you will learn the commonly accepted measures of project performance. Earned value management (EVM) uses measures of the value of work completed to make comparisons to the baseline budget and schedule. The results of this analysis guide the project manager in determining whether changes to the project plan or project resources will be needed in order to meet the budget and schedule baselines. The specific tools of EVM are often referred to as earned value analysis (EVA). EVA can occur many times throughout the execution of the project as part of the monitoring of project performance. This lesson will introduce each of the measures and show you how they are calculated. You will use a sample project to calculate each measure and explain how the project manager would interpret the results.

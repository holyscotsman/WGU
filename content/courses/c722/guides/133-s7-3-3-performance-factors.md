# S7 3.3 Performance Factors

## Learning Objectives

Determine the progress of a project given various earned value scenarios.

The Cost Performance Index (CPI) The cost performance index (CPI) uses the same inputs as the CV measure but combines them using a ratio that creates a measure of cost efficiency.

## CPI = EV/AC

Using the same measures from the website project at the end of Week 3, you can calculate the CPI:

- CPI = EV/AC
- CPI = $42,500/$40,000
- CPI = 1.06 or 106%

CPI values greater than 1 or 100% mean that the project team is completing more work with less cost than expected. This is a good result. If the CPI had been less than 1, like 0.8 for example, the project team would be accomplishing less work for the money spent and is behind the budget. If the CPI is 0.8 or 80%, then the team is only 80% efficient in their use of the project money.

The Schedule Performance Index (SPI) The schedule performance index (SPI) uses the same inputs as the SV measure but combines them using a ratio that creates a measure of time efficiency.

## SPI = EV/PV

Using the same measures from the website project at the end of Week 3, you can calculate the SPI:

- SPI = EV/PV
- SPI = $42,500/$60,000
- SPI = 0.71 or 71%

SPI values greater than 1 mean that the project team is completing more work in less time than expected. This is a good result. In this case, SPI is less than 1, which indicates that the project team is accomplishing less work for the time allowed. An SPI of 0.71 or 71% means that the team is only 71% efficient in their use of time.

The To-Complete Performance Index (TCPI) The to-complete performance index (TCPI) is essentially what the CPI will need to be for the remainder of the project if the team intends to finish on budget. TCPI is calculated by dividing the remaining work by the remaining budget. The difficulty of this estimate is that the measure of remaining budget changes depending on whether you are currently over budget or currently under budget. Calculating TCPI when the project is currently under budget:

- TCPI = (BAC − EV)/(BAC − AC)

Calculating TCPI when the project is currently over budget and the customer has approved that the new estimated cost at completion (EAC) will be used as the final target instead of the original baseline budget at completion (BAC):

- TCPI = (BAC − EV)/(EAC − AC)

Notice that the only difference between the two equations is whether the estimate is based on the original budget (BAC) or the calculated budget with a cost overrun (EAC). In the website project example, the EAC is estimating a cost overrun of $20.986. In this case, the TCPI can be calculated based on the original baseline budget (BAC). The result will be a measure of how efficient the team will need to be on the remainder of the project work in order to still complete the project on budget. TCPI = (BAC − EV)/(BAC − AC) TCPI = ($100,000 − $42,500)/($100,000 − $40,000)

## TCPI = 0.958 or rounded to 0.96

If the calculated TCPI is higher than the current CPI, the team will need to improve their cost efficiency on the remaining work if they are going to complete the project on budget. If the calculated TCPI is lower than the current CPI, then the team is in good shape and will likely finish the project on budget even if they decrease their cost efficiency. In the example, the current CPI is 1.06 or higher than the .96, and the project is moving along nicely.

When using these indicators, it allows the project manager and key stakeholders to determine if it is feasible for the team to improve their cost efficiency on the remaining work. This may require changing work practices, changing resources, or replanning parts of the remaining work. If improving the cost efficiency of the team is not feasible, then the customer will need to consider increasing the budget, increasing the time, or decreasing the scope.

## The Percent Complete Index

The percent complete index is a measure of how much of the total project work has been completed. While it is officially called an index, it is actually an estimate of project completeness and is included as an estimate rather than with the previous efficiency indexes. There are two methods to calculate this measure depending on whether the original baseline budget (BAC) is still a realistic goal or whether the recently calculated estimate at completion (EAC) has become the standard. If the original baseline budget stands, then you estimate percent complete using the percent complete index—budget (PCIB).

## PCIB = EV/BAC

Using the website project measures from the end of Week 3 and assuming that the original budget is still appropriate, the PCIB would be calculated as follows:

- PCIB = EV/BAC
- PCIB = $42,500/$100,000
- PCIB = 0.425 or 43%

The PCIB of 43% would indicate that based on the current work completed and the original budget, the team has completed 43% of the project work. The percent complete index—cost (PCIC) is used only when the customer and project team have agreed to a new budget at completion (BAC). Since the new budget has been put in place, the current actual costs (AC) are accepted as the current earned value (EV), and the new budget (EAC) replaces the original BAC. Recall that the EV and BAC were used to calculate PCIB. At this point in time, the budget has been reset, so the PCIC can be calculated using either the EV or the AC in the numerator. Project managers often prefer the use of AC and EAC in the calculation of PCIC since these measures recognize the current cost and current budget status to provide a reliable estimate of percent complete.

## PCIC = AC/*EAC

*where the revised budget (EAC) has been approved Using the website project measures from the end of Week 3 and assuming that the new estimate of completion has been approved as the target budget, the PCIC is calculated as follows:

- PCIC = AC/EAC (revised budget)
- PCIC = $40,000/$120,986
- PCIC = 0.33 or 33%

The PCIC of 33% indicates that based on the current estimate of completion and actual costs, the project team has completed 33% of the project work at the end of Week 3.

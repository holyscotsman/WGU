# S7 3.4 Estimates

## Learning Objectives

Determine the progress of a project given various earned value scenarios.

## Earned Value

The earned value analysis (EVA) values and the indexes calculated by the project manager can be used to predict how the project will end. Two of these estimates assume that the efficiency of how the team is using money will continue until project completion. If the team becomes more or less efficient based on the cost performance index (CPI), the estimates will need to be revised. The third estimate shows what the efficiency will need to be for the rest of the project in order to finish at the original budget. Finally, the efficiency estimates and budget predictions can be used to calculate how much of the project work has been completed.

The estimate to completion (ETC) provides an estimate of how much money will be needed to complete the project. It is based on the CPI measure of cost efficiency and how much of the baseline total budget has already been expended.

## ETC = (BAC − EV)/CPI

Using the index and EVA measures from the website project at the end of Week 3, the ETC for the project can be calculated as follows:

- ETC = (BAC − EV)/CPI
- ETC = ($100,000 − 42,500)/1.06
- ETC = $54,245.28 or rounded to $54,245

The estimate at completion (EAC) is the new forecast of how much more in total the project is expected to cost once completed.

## EAC = AC + ETC

You can estimate the new total estimated cost of the website project based on the current amount spent and the estimate of costs to still occur:

- EAC = AC + ETC
- EAC = $40,000 + $54245
- EAC = $94,245

The original budget at completion was $100,000; the EAC is predicting a $5.755 cost saving based on the current cost efficiency as measured by the CPI.

## Overview of the EVA Process

In summary, there are four major steps in completing an EVA analysis. First, based on the desired time period, the four EVA measures must be gathered from the project records. The four measures are actual cost (AC), earned value (EV), planned value (PV), and budget at completion (BAC). Second, using those measures, the cost variance (CV), schedule variance (SV), and percent complete (PCIB) can be calculated. Third, the same EVA measures are used to calculate the time and cost efficiency indexes of the cost performance index (CPI) and schedule performance index (SPI). Finally, the EVA measures and the indexes are combined to calculate estimates of the final cost of the project. Two estimates are the estimate to completion (ETC) and the estimate at completion (EAC). The to-complete percent index (TCPI) can be calculated to determine how the team will need to perform for the remainder of the project in order to finish on budget. Finally, the percent complete (PCIB or PCIC) can be calculated to provide a measure of the proportion of the project work that has been completed.

To analyze EVA, one needs to follow a number of steps. The first step includes gathering EVA measures like AC, EV, PV, and BAC. The following step includes calculating variances like CV and SV. The next step includes calculating indexes like CPI and SPI. The final and ultimate step includes calculating estimates like ETC, EAC, TCPI, and PCIB or PCIC. The four steps help with analyzing the EVA process smoothly.

# S7 3 Summary

## Summary

In this lesson, you learned the process of earned value management (EVM), which is used to monitor project performance during the execution phase. The specific measures, variances indexes, and estimates provide the project manager with valuable information about the status of the project. In earned value analysis, the value of actual work completed to date is compared to the baseline schedule and budget. The results are measures of how efficiently the team is using time and money to complete the project work. Based on these measures of efficiency, predictions can be made of how the project will end with respect to the baseline budget. The information gathered during the EVM process will be used to control the project. As a result of the analysis, the project manager may need to make changes to how the project is being executed, or the project manager may need to work with the customer to change the budget, schedule, or scope of the project. How often this is done depends on the length and complexity of the project. It is time-consuming and often done based on organizational procedures or if the project manager is concerned. The project manager’s "gut" can be a good guide on when this should be done.

# S7 2 Introduction

## Learning Objectives

Consider the following learning objectives as you move through the lesson:

- Describe how managers monitor against project baselines.
- Describe project change management processes.
- Describe the principles of quality management.

## Overview

After the project plans have been developed, they are approved. This sets the baseline scope, schedule, and budget. At this point, the team turns their focus to executing the plans to create the project outcomes, and the project manager focuses on monitoring project performance. In a perfect world, nothing in the project environment changes. The plans are perfectly developed to achieve the scope, schedule, and budget, so monitoring is easy. The project manager will use reports and other inputs to verify and communicate that everything is going according to plan and will meet the customer’s expectations. Unfortunately, plans are seldom perfect, and project conditions often change during execution. A critical role of the project manager is monitoring to detect when project performance is moving in a direction that will not result in the project meeting the customer’s expectations. Monitoring occurs throughout project execution so that adjustments can be made to keep the project on track or to notify key stakeholders that changes to the scope, schedule, or budget are necessary. Earlier in the course, you were introduced to monitoring and controlling as iterative processes that occur during project execution. Essentially, the monitoring is checking actual project performance against the baselines. Controlling is taking action if the actual performance is not in

sync with the baseline.

The figure shown depicts the planning, executing, monitoring and controlling and arrow pointing to closing. This image shows the iterative process of monitoring and controlling during execution. You have an iterative situation because the controlling processes may result in changes to the project plans before the team can return to executing. If the monitoring processes confirm that everything is going as planned, then the team keeps on executing.

This lesson will introduce the processes related to monitoring and controlling project scope, budget, schedule, quality, and risk.

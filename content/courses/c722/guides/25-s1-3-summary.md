# S1 3 Summary

## Summary

In this lesson, you learned the advantages and disadvantages of common types of organizational structures: functional (departmentalized), projectized, and matrix. You examined the strengths and weaknesses of each type of structure and discussed the project manager’s level of authority within each structure type. In a functional organization, a project manager’s authority is minimal, in a weak matrix it is low, in a balanced matrix it is moderate, in a strong matrix the project manager’s authority is high, and in a projectized organization, the project manager has a significant amount of power and authority over the project. You also learned the advantages of having a project management office. The lesson explained the five different organizational maturity levels and how to identify an organization’s project maturity level.

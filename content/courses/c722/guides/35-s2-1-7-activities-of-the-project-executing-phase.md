# S2 1.7 Activities of the Project Executing Phase

## Learning Objectives

Describe the activities of each phase of a project.

## Project Executing Phase

The project executing phase is when the project manager and the project team roll up their sleeves and complete the work activities identified in the project plan. During the executing phase, needed talent is added to the project team. The human resources management plan will guide the project manager in how to select team members and will then provide them with project orientation and training. The procurement people will use the procurement management plan to begin acquiring external materials or services needed for the project. Project team members will begin completing activities that create the project outcomes or will be related to the various planning areas (communication, quality, stakeholder management, etc.) to ensure that the project is delivered as planned. While all this work is being completed, the project manager is busy directing and managing the project work. A large part of this effort will involve reviewing data and reports to monitor project progress and identify issues as they arise. Some major areas for monitoring include cost, schedule, scope, and quality. During the monitoring process, if the project manager detects the project is not being executed as planned, they may need to intercede in order to correct the situation. This process is called monitoring and controlling. It is central to the project manager’s role to know the status of the project work (monitor) and take action as needed to ensure the project plan is completed as planned (control). The project manager may discover that the project plan cannot be executed as originally developed and that portions need to be replanned. This is another iterative process in which execution, monitoring, and controlling occurs. Monitoring and controlling may require replanning and then returning to executing. In this iterative way, the plan acts as a foundation so smart decisions can be made about things rather than shooting from the hip. Often, more than half of a project manager’s time is spent on problem resolution around interpreting the elements of the plan.

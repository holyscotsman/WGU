# Section 6: Summary

## Section 6: Summary

This section illustrated the skills needed to finish building the project plan. The Team, Development Approach, Planning, Delivery, and Uncertainty performance domains that integrate scheduling and time management were introduced. You learned how the project team estimates work durations using one-point, triangular distribution, or beta distributions so that a project schedule can be developed. Once the durations of each work activity are established, using the critical path method and PERT, the team determines the sequencing of activities, and the network diagram is produced.

The forward and backward pass technique was introduced to produce a detailed schedule. The detailed schedule specifies the start date, finish date, and slack for each work activity. Activities with slack have the flexibility to start earlier or later without affecting the overall completion date of the project. The development of the schedule and network diagram is based on the same work breakdown activities used to develop the budget.

At this point, you have completed the planning steps necessary to approve a baseline and begin project execution.

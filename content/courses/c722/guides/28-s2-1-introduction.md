# S2 1 Introduction

## Learning Objectives

Consider the following learning objectives as you move through the lesson:

Identify each phase of a project.

Describe the activities of each phase of a project.

Explain the purpose of developing project lessons learned.

## Overview

In this lesson, we will discuss these four phases of the project life cycle in detail so that you can understand the changes that occur as the project moves from inception to completion. This lesson will wrap up by explaining how lessons learned benefit the project organization.

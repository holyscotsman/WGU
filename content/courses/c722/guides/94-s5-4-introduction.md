# S5 4 Introduction

## Learning Objectives

Consider the following learning objectives as you move through the lesson:

- Describe the different types of estimation techniques.
- Explain how to construct a project budget.
- Prepare a calendarized project budget.

## A calculator, a pen, and papers showing a spreadsheet and graphs

Developing the project budget involves providing estimates of the types and amount of resources that will be required to complete the project, as well as costs for the resources. On a simple project, the process can be as straightforward as gathering accurate estimates for each work activity identified in the WBS and obtaining customer approval to move forward. However, projects can be quite complex, and project managers find that they need to use several estimating methods to develop a reasonable budget that can be used to fund and control the project. In this lesson, you will be introduced to several methods used by project managers. As mentioned, the methods are not exclusive, so the project manager can combine them or develop their own method depending on the situation. Regardless of the method used, the goal is to develop a budget that is as accurate as possible.

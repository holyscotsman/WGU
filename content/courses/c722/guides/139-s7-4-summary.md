# S7 4 Summary

## Summary

In this lesson, you reviewed the final function of the project manager: closing out the project. This is a formal process that ensures all project tasks have been successfully completed. Supplier contracts are closed, and suppliers are paid. Team members are released from the project and become available for future projects. All project work is documented. If a project was terminated early, the reasons have been documented. One of the very important tasks in the project closeout is the lessons learned review. This is a formal process where all project activities are reviewed to determine what went right and what went wrong, what was done well and what could be improved. It is an opportunity to learn and improve for the next project.

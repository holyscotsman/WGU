# S6 2.4 Gantt Charts

## Learning Objectives

Describe how a Gantt chart is used in project scheduling.

## Identifying Lag in a Project Gantt Chart

Another chart often used to visually depict relationships on a project is a Gantt chart. It is a bar graph that shows the relationships in yet another format and can track more detail on each task and activity. One of its most visual relationships is time relationships with lag and lead time.

When linking tasks, you can add a lead or lag time to extend a link backward or forward so that the successor task starts earlier or later than it otherwise would. For a default finish-to-start (FS) link, this either introduces an overlap (lead time), so the successor task starts before its predecessor ends, or it introduces a delay (lag time) that makes the successor task start at some point in time after its predecessor ends. In this example, there is a lag time of four days between the FS activities so that the concrete has time to cure completely before the crew arrives to seal the concrete.

The Start activity involves pouring concrete and the Finish activity involves sealing concrete. In this Start-to-Finish relationship, there is a lead or lag time of four days. The arrow directs from the Start activity box to the Finish activity box. Inserting a lead time between tasks can help shorten the overall duration of the project by allowing the successor task to start prior to completion of its predecessor. These situations can be more challenging to identify and manage, but whenever feasible, they can be advantageous to shortening the schedule. In the restaurant example, if the floor installation requires several days, 2020 rather than waiting until the installation is complete, the painters could return for touch-up and work in areas where the floor has been completed. The FS relationship with a two-day lead time inserted would bring the painters back two days prior to the completion of the flooring installation.

The Start activity includes Touch up Paint and the Finish activity includes Install Flooring. There is a lead or lag time of two days, which facilitates the process. The arrow directs from the Finish activity box to the Start activity box. The lead time often helps in shortening the schedule of the estimated project delivery time.

## Identifying Resources for Project Tasks

For every activity and task you identify, you also must identify the resource required to perform the work. This can be a person or human resource, types and quantity of materials like paint or furnishings, equipment, or any types of supplies. This information is required to estimate time and cost. If you need to hire employees or subcontractors to do the work, you need to know the lead time required for estimating your project schedule. If you need money, this will require time to request and obtain funding.

2020 Inputs to this process come from all the planning steps, including project and product scopes to work breakdown structure (WBS) to risk management to budgeting to expert estimating. Of particular interest can be the procurement plan where you understand the processes for gaining resources as well as descriptions of what is available. Many organizations have existing policies and practices regarding human resources and procurement so they must be observed.

The estimating of resources is done by using expert advice and research. The resources can come from within or outside of the organization hosting the project. It is an estimate based on all the information that has been collected and will be refined as the knowledge base grows. As with other aspects, it is good to use the person who will be completing the task for doing the estimating and creating ownership to the task and the time estimates.

In the restaurant example, when the chef is defining the menu, there is often a shopping list of food and kitchen supplies created with the menu, and then the menu is tested and preparation timing can be estimated. The chef should have lots of experience in estimating what time it will take to set up the kitchen, defining the human resources needed, determining the time needed to train the staff, and determining the time required to procure what is needed. All of these resources will be estimated at the activity or task level and included in the schedule and procurement plans based on expertise and experience.

## Project Information Within a Gantt Chart

Gantt charts are another form of graphically displaying the relationships of tasks. The key stages of a project and their duration are displayed as a bar chart, with the time scale across the top. The key activities or stages of the project are listed in sequence as rows down the left margin. The bars in the body of the chart show when work on each activity will occur. The bars are placed in sequence, starting in the top left corner and ending in the bottom right corner.

A Gantt chart can be drawn quickly and easily using traditional spreadsheet software or project management software. A project manager may work with the team to draw it using rough estimates of the time that it will take to complete the key tasks. The detailed Gantt chart is usually constructed after the main deliverables and requirements have been broken down into activities and tasks.

The Gantt chart has the number of weeks, the Key Stage, and the Code. Key Stage A is Secure Funds, Key Stage B is Negotiate with Other agencies, Key Stage C is Form Advisory Group, Key Stage D is Establish Data Collection Plan, Key Stage E is Collect Data, Key Stage F is Write Directory 2020 Text, Key Stage G is Identify Printer, Key Stage H is Agree Print Contract, Key Stage I is Print Directory, Key Stage J is Agree Distribution Plan, Key Stage K is Organize Distribution and Key Stage L is Distribute Directory. The weeks are marked from Week 1 to Week 28.

In this example, Key Stage K (organize distribution) starts at Week 23 so that its end point coincides with Key Stage L (distribute directory). However, K could begin as early as Week 17, as soon as Key Stage J is completed. Key Stage K is therefore said to have "float." Key Stage H (agree print contract) has been placed to end at Week 12. However, it could end as late as Week 22, because Key Stage I (print directory) does not begin until Week 23. Key Stage H is therefore said to have "float." Float time (also referred to as slack) can be indicated on the chart by adding a line ahead of the bar to the latest possible end point. Float shows you where there is flexibility in the schedule, and this can be useful when you need to gain time once the project is up and running.

You can add other information to a Gantt chart, for example:

Milestones could be indicated by using a symbol such as a diamond or triangle.

Project meetings could be indicated by another symbol, such as a circle.

Reviews of progress and status reports could be indicated.

For a complex project, you may decide to produce a separate Gantt chart for each of the key stages. If you do this shortly before each key stage begins, you will be able to take any last- minute happenings or events into account. These charts provide a useful tool for monitoring and control as the project progresses.

Gantt charts are relatively easy to draw by hand, but this does not offer the same level of flexibility 2020 during monitoring that you would get from a software package. Various programs are available to assist project managers in scheduling and control. Once the data have been entered, a program helps you to work on "what-if" scenarios, showing what might happen if a key stage is delayed or sped up. This is more difficult if you are working manually.

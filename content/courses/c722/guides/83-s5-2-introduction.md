# S5 2 Introduction

## Learning Objectives

Consider the following learning objectives as you move through the lesson: Describe how a project's work breakdown structure is created. Prepare a work breakdown structure given a project scenario.

## Honor Code

A work breakdown structure, WBS, breaks expectations down into discrete tasks that can be assigned to the right resources. A structure shows a person leading a group. The leader is dividing the project tasks and assigning them to the correct people. Finally, the completed project reaches the customer. Once you understand the expectations of the stakeholders and the project deliverables expressed in the project scope and the product scope, you need to further express what steps you will need to take to meet those expectations. You will break down these expectations into activities and tasks that can be assigned to the correct resource people. This process is called work breakdown structure, or WBS. In this lesson, you will learn the methods used by project managers to divide up deliverables into bite-size work packets and organize them as activities and tasks within activities. As mentioned, the methods are not exclusive, so the project manager selects elements that work or modify the process into a better working method depending on the situation. Regardless of the method used, the goal is to create a blueprint that leads you to develop a work plan for delivering exactly what is contracted for in the scope of the project.
